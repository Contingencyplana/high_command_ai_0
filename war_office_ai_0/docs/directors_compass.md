# Director's Compass Ritual

Before any War Office directive:
1. **Front** — Name the active theatre/front (e.g., Alfa Zero Nightlands duet).
2. **Milestone** — State the target milestone or slice.
3. **Goal** — State the intended outcome / change.

Record the trio under `logs/session_<timestamp>.md`, cite Love/Light/Safety/Sanity pillar emphasis, and only then ask Codex for the next move. This sheet anchors the Nightlands Director Protocol inside war_office_ai_0.
