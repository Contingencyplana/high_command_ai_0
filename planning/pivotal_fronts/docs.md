# Documentation Front

Purpose
- Make doctrine and plans clear, parseable, and actionable for humans and AI tooling.

Standards
- Use Safety Notes sections on planning docs linking to concrete policies/gates.
- Prefer structured templates (RFC, runbooks, decision memos) and schemas where applicable.
- Plain, concise language; stable headings; predictable file names.
- Reference the Tenfold genesis table (`planning/pivotal_fronts/genesis_workspaces.md`) and the War Office workspace (`war_office_ai_0`) when documentation touches civilian oversight; include War Office dispatch/ledger IDs and civic lattice guild/house/citizen tags where mission restatement applies.

Tooling & Links
- Templates: planning/templates/
- Policies: policies/*; Exchange interfaces: exchange/interfaces.md
- Schemas: exchange/schemas/*.schema.json
- War Office repo docs: `war_office_ai_0/docs/civic_lattice.md`, `war_office_ai_0/docs/directors_compass.md`

Acceptance Checks
- New planning docs include "Safety Notes (valiant_citadel_ai_0)" with concrete links.
- Required runbooks/policies present; validator passes.
- Docs support watcher/gates without ambiguity and cite War Office artifacts when Tenfold structure, civic slots, or Director's Compass rituals are involved.
