# Fun Guardian Protocol (Pivot Seven)

Objective: Monitor engagement signals and propose non-destructive overlays (Outlands) to restore or elevate fun.

Signals (inputs)
- Session sentiment (self-report or lightweight prompts)
- Interaction cadence (clicks/turns/minute, retry loops)
- Comfort telemetry (narrator/telemetry shells)
- Contract friction (failing cases clustering)

Actions (outputs)
- Suggest overlay_id (lore|music|ritual|emergent)
- Provide evidence targets (trace files, ledger tags)
- Ask-for-confirmation step before activation (human-in-the-loop)

Interfaces
- Read-only hooks into telemetry JSONL
- Suggestion channel to controller/UI
- Exchange tagging for overlay activation/deactivation

Open items
- Define engagement heuristics and thresholds
- Draft JSON schema for suggestions and operator acks
